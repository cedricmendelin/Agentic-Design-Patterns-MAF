## Project Context

- **Project:** Agentic-Design-Patterns-MAF
- **Created:** 2026-11-12
- **Focus:** Readable, runnable C#/Microsoft Agent Framework pattern demos, deterministic contracts and educational documentation.
- **Ownership:** Coder owns reusable pattern logic; Foundry owns hosted-agent integration. Researcher proposes patterns; Architect assesses fit and refines requirements.
- **Naming:** Descriptive functional names, retaining the seven approved specialist identities.
- **Authority:** Research produces proposals, not implementation issues. Implementation issue creation, cloud operations, secret access, paid live calls and merges require explicit user approval. Installing workflows does not grant that approval.
